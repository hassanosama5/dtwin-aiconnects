# Decision Twin Setup

## Clone

git clone <repo>

## Install

npm install

## Environment

Copy:

.env.example

to

.env.local

Fill in:

- Anthropic API key
- Supabase URL
- Supabase anon key

## Start

npx expo start

## Before coding

Run Claude Code and let it read:

1. CLAUDE.md
2. ROADMAP.md
3. PROJECT_SPEC.md
4. ARCHITECTURE.md
5. DECISIONS.md
6. TASKS.md

before making any changes.
